# Portfolio

Personal portfolio website for an **Engineering Physics undergraduate** at Tecnológico de Monterrey, specializing in scientific computing and materials informatics.

## Topics
- Materials Science & 2D Materials (Siligraphene, DFT)
- Semiconductor TCAD
- Physics-Informed Machine Learning (PINNs / PIMLs)
- Ab-initio methods (Quantum ESPRESSO)

## Stack
Plain HTML · CSS · Vanilla JS — no frameworks, no build step.

## Live Site
Open `index.html` directly in a browser, or deploy to GitHub Pages.
